# 🌐 Projetos HTML

Repositório criado para organizar e documentar os códigos-fonte, sites e exercícios práticos construídos ao longo do curso técnico em Desenvolvimento de Sistemas. 

## 🚀 Tecnologias e Ferramentas

* **HTML5:** Estruturação semântica e conteúdo das páginas web.
* **CSS3:** Estilização visual (para os projetos que possuem design).
* **Ferramentas:** Visual Studio Code, Git e GitHub.

## 📂 Sobre o Repositório

Aqui estão reunidos todos os testes e atividades práticas. Os arquivos estão organizados em pastas temáticas para facilitar a navegação e a consulta rápida dos códigos desenvolvidos durante as aulas.
