# Meu Portal de Entretenimento Digital 🎬🎵🎮

Projeto desenvolvido para a atividade de Programação Web, com o objetivo de criar uma página estruturada em três seções principais utilizando HTML5 e CSS3 moderno.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Marcação estrutural da página dividida em colunas.
* **CSS3:** Estilização visual dividida em três abordagens:
  * *Externo:* Arquivo principal (`estilo.css`).
  * *Interno:* Bloco `<style>` no cabeçalho.
  * *Inline:* Aplicado diretamente em elementos específicos.
* **Flexbox:** Modelo de layout utilizado para organizar as três seções lado a lado de forma responsiva.
* **CSS Reset:** Baseado no modelo de Eric Meyer para padronização entre navegadores.
